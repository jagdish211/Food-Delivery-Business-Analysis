# 🍔 Food Delivery Data Analysis

## 📌 Project Overview

This project analyzes food delivery order data to understand customer behavior, restaurant performance, revenue trends, payment preferences, and delivery performance.

The project follows a complete Data Analyst workflow:

**Raw Data → Data Cleaning → EDA → Business Analysis → Data Visualization → Business Insights**

---

## 🎯 Project Objectives

- Analyze daily order trends
- Analyze daily revenue
- Understand customer types and purchasing behavior
- Analyze customer age groups
- Identify cities with the highest number of orders
- Analyze restaurant categories
- Understand payment method preferences
- Analyze traffic levels and delivery time
- Identify weather conditions associated with late deliveries
- Study the relationship between delivery distance and delivery time

---
